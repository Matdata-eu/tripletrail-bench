# Geographica 2 query lists

The query lists of the Geographica 2 benchmark, copied unchanged from its repository
[AI-team-UoA/Geographica2](https://github.com/AI-team-UoA/Geographica2) (Apache License 2.0).
`../../data/fetch_inputs.sh` puts them next to the datasets, which are downloaded from
https://geographica2.di.uoa.gr/ at run time and never copied into this repository.
